---
title: View Policy Metadata
description: >-
  Retrieve entity-level metadata for a policy — which entities are anonymizable,
  pseudonymizable, or excluded.
---
Retrieves entity-level metadata for a specific policy, showing which entities are anonymizable, pseudonymizable, or excluded.

## Endpoint

| Method | Endpoint                                                          |
| ------ | ----------------------------------------------------------------- |
| `GET`  | `{baseurl}/api/vault/metadata/personal-data-entities/list` |

## Query parameters

<ParamField query="policy_name" param-type="string" required="false" deprecated="false">
  Policy to retrieve metadata for. If omitted, returns the master entity list without policy-specific overrides.
</ParamField>

<ParamField query="next_page_token" param-type="string" required="false" deprecated="false">
  Pagination token for large result sets.
</ParamField>

<Request show-lines="true" tabs={[]}>
  ```bash
  curl -X GET "{baseurl}/api/vault/metadata/personal-data-entities/list?policy_name=customer-support-policy" \
    -H "Authorization: Bearer <NAMESPACE_ADMIN_API_KEY>"
  ```
</Request>

## Entity categories

| Category                   | Behavior                                                     |
| --------------------------- | ------------------------------------------------------------ |
| `anonymizable_entities`    | Masked and **cannot be unmasked** — irreversible             |
| `pseudonymizable_entities` | Masked and **can be unmasked** — reversible with permissions |
| `excluded_entities`        | Not detected or masked — appear as plain text                |
