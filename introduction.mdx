## Overview

Protecto is an API-first data protection platform that helps engineering teams identify, tokenize, mask, and safely handle sensitive data across applications, data pipelines, and GenAI workflows.

At its core, Protecto lets you replace sensitive values like names, emails, phone numbers, IDs, and financial data with secure, consistent tokens, while still keeping the data usable for analytics, logging, debugging, and AI inference.

Protecto is designed to sit directly in your application flow. You call the API where data enters or leaves your system, and Protecto handles detection, masking, and optional unmasking under strict authorization.

<Callout kind="info">

**Base URL (Trial)**  
`https://protecto-trial.protecto.ai`

All APIs are JSON-based and follow standard HTTP semantics.

</Callout>

## Why Protecto

Most teams run into the same problems when dealing with sensitive data:

| Problem           | What typically goes wrong                              |
| ---------------- | ------------------------------------------------------- |
| Manual masking   | Hard-coded regexes break and miss edge cases           |
| Inconsistent tokens | Same value masked differently across systems        |
| GenAI leakage    | Prompts and responses accidentally expose PII          |
| Compliance pressure | No clear audit trail or retention controls          |
| Performance      | Heavy privacy tooling slows down core services         |

Protecto addresses these issues by providing centralized, deterministic tokenization with APIs that are fast enough for real-time use and flexible enough for batch processing.

What makes Protecto different in practice:

- Auto-detect unknown PII in free-form text.
- Keep tokens consistent across calls when you use the same token type.
- Control who can unmask, and under which permissions.
- Use async APIs to handle large payloads without timeouts.
- Apply built-in toxicity scoring to protect GenAI workflows.

## Key capabilities

### Core tokenization and masking

Use these APIs to mask and unmask sensitive values while keeping data usable.

| Capability        | Description                                        | Primary endpoint                                                              |
| ----------------- | -------------------------------------------------- | ----------------------------------------------------------------------------- |
| Mask with token   | Mask values when you already know the data type   | `PUT https://protecto-trial.protecto.ai/api/vault/mask`                       |
| Mask with format  | Preserve structure like email, phone, URL         | `PUT https://protecto-trial.protecto.ai/api/vault/mask`                       |
| Identify & mask   | Auto-detect and mask all PII in text              | `PUT https://protecto-trial.protecto.ai/api/vault/mask`                       |
| Unmask            | Retrieve original values with authorization       | `PUT https://protecto-trial.protecto.ai/api/vault/unmask`                     |

### Asynchronous processing

Use async endpoints for large payloads or batch operations.

| Capability    | Description                            | Endpoint                                                                                |
| ------------- | -------------------------------------- | --------------------------------------------------------------------------------------- |
| Async mask    | Mask large payloads without blocking   | `PUT https://protecto-trial.protecto.ai/api/vault/mask/async`                          |
| Async unmask  | Bulk unmasking                         | `PUT https://protecto-trial.protecto.ai/api/vault/umask/async`                          |
| Status tracking | Track async job lifecycle           | `PUT https://protecto-trial.protecto.ai/api/vault/api/vault/async-status`              |

### Data discovery and governance (Paid)

Use these capabilities in paid plans to manage PII across your data estate and enforce policies.

| Capability   | Description                                      |
| ------------ | ------------------------------------------------ |
| Data scan    | Discover PII across databases and tables        |
| Policies     | Control anonymization vs pseudonymization       |
| Custom PII   | Define company-specific identifiers             |
| Audit & reports | Track usage, access, and compliance         |
| Data deletion | Enforce retention and cleanup rules           |

## Trial limits

The trial is designed for quick evaluation in development and staging environments.

| Limit            | Value         |
| ---------------- | ------------- |
| Trial duration   | 14 days       |
| Max masked entries | 1000 values |
| Rate limits      | Enforced      |
| Subscription APIs | Disabled     |

If you hit a hard limit during evaluation, the API returns explicit error messages so you know exactly why a request failed.
