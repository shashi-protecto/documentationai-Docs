## Overview

Protecto helps you safeguard sensitive data across analytics, data pipelines, and GenAI workflows without slowing down development. You can discover and classify sensitive data like PII and PHI, apply masking and redaction policies at scale, and protect data in real time for dashboards, APIs, and GenAI models.

Protecto integrates seamlessly with your existing systems such as Snowflake, BigQuery, S3, and Redshift, handling both structured and unstructured data sources.

## Quick Start

Get up and running in minutes.

<Steps>
  <Step title="Sign Up" icon="user-plus" title-type="p">
    Create an account at [https://dashboard.protecto.ai](https://dashboard.protecto.ai) and generate your API key.
  </Step>

  <Step title="Authenticate" icon="key" title-type="p">
    Use your API key to make your first request.

    <CodeGroup show-lines="true" tabs={[]}>
      ```javascript
      const response = await fetch('https://api.protecto.ai/v1/discover', {
        headers: {
          'Authorization': `Bearer ${YOUR_API_KEY}`
        }
      });
      const data = await response.json();
      console.log(data);
      ```

      ```python
      import requests

      headers = {'Authorization': f'Bearer {YOUR_API_KEY}'}
      response = requests.get('https://api.protecto.ai/v1/discover', headers=headers)
      print(response.json())
      ```
    </CodeGroup>
  </Step>

  <Step title="Scan Data" icon="search" title-type="p">
    Connect your data source and run a discovery scan via the dashboard or API.

</Steps>
