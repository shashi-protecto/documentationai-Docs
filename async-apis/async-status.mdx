---
title: Async Status Tracking
description: >-
  Poll the status of an async mask or unmask job using a tracking ID, and
  retrieve results when the job completes.
---
Fetches the current status of an async job and returns the original input payload, final output (when ready), timestamps, and error details when applicable.

## Endpoint

| Method | URL                      |
| ------ | ------------------------ |
| PUT    | `{baseurl}/async-status` |

## Request body

<ParamField body="status" param-type="array" required="true" deprecated="false">
  List of tracking IDs to check status for.
</ParamField>

<ParamField body="status[].tracking_id" param-type="string" required="true" deprecated="false">
  The tracking ID returned by the async submit endpoint.
</ParamField>

<Request show-lines="true" tabs={[]}>
  ```json
  {
    "status": [
      { "tracking_id": "747027ff-5ce7-4780-8cca-000f908edae721052025073644" }
    ]
  }
  ```

  ```bash
  curl -X PUT https://protecto-trial.protecto.ai/api/vault/async-status \
    -H "Authorization: Bearer YOUR_AUTH_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "status": [
        { "tracking_id": "747027ff-5ce7-4780-8cca-000f908edae721052025073644" }
      ]
    }'
  ```

  ```python
  import requests, time

  def poll_status(tracking_id, token, interval=30):
      while True:
          response = requests.put(
              "https://protecto-trial.protecto.ai/api/vault/async-status",
              headers={"Authorization": f"Bearer {token}", "Content-Type": "application/json"},
              json={"status": [{"tracking_id": tracking_id}]}
          )
          job = response.json()["data"][0]
          if job["status"] in ("SUCCESS", "FAILED", "PURGED"):
              return job
          time.sleep(interval)
  ```
</Request>

## Response fields

<ResponseField name="tracking_id" field-type="string" required="true" deprecated="false">
  The job identifier.
</ResponseField>

<ResponseField name="call_type" field-type="string" required="true" deprecated="false">
  Either `mask` or `unmask`.
</ResponseField>

<ResponseField name="status" field-type="string" required="true" deprecated="false">
  Current job state: `PENDING`, `IN-PROGRESS`, `SUCCESS`, `FAILED`, or `PURGED`.
</ResponseField>

<ResponseField name="result" field-type="array" required="false" deprecated="false">
  The masking or unmasking output. Only present when `status` is `SUCCESS`.
</ResponseField>

<ResponseField name="error_msg" field-type="string" required="false" deprecated="false">
  Error description. Only present when `status` is `FAILED`.
</ResponseField>

<ResponseField name="submitted_time" field-type="string" required="true" deprecated="false">
  Timestamp when the job was submitted.
</ResponseField>

<ResponseField name="completed_time" field-type="string" required="false" deprecated="false">
  Timestamp when the job finished. `"None"` if still in progress.
</ResponseField>
