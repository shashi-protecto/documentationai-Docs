---
title: "User Namespace Summary"
description: "API usage per user within a namespace — call counts, success rates, and login times over a date range."
---

Returns **API usage per user** within a namespace over a given time range. Use this to understand which users are actively calling APIs, how long they were active, and whether their calls succeeded.

## Endpoint

| Method | Endpoint |
|--------|----------|
| `GET` | `https://<domain>/api/vault/reports/namespace-users-summary` |

## Query parameters

<ParamField query="namespace" param-type="string" required="true">
  Namespace name to report on.
</ParamField>

<ParamField query="start_date" param-type="string" required="true">
  Start of the reporting window. Format: `YYYY-MM-DD HH:MM:SS`.
</ParamField>

<ParamField query="end_date" param-type="string" required="true">
  End of the reporting window. Format: `YYYY-MM-DD HH:MM:SS`.
</ParamField>

<ParamField query="next_page_token" param-type="string" required="false">
  Pagination token for large result sets.
</ParamField>

<Request tabs="JSON,cURL,Python">
```json
{
  "namespace": "production",
  "start_date": "2024-05-21 00:00:00",
  "end_date": "2024-05-22 23:59:59"
}
```

```bash
curl -X GET "https://<domain>/api/vault/reports/namespace-users-summary?namespace=production&start_date=2024-05-21+00:00:00&end_date=2024-05-22+23:59:59" \
  -H "Authorization: Bearer <ADMIN_USER_AUTH_KEY>"
```

```python
import requests

response = requests.get(
    "https://<domain>/api/vault/reports/namespace-users-summary",
    headers={
        "Authorization": "Bearer <ADMIN_USER_AUTH_KEY>"
    },
    params={
        "namespace": "production",
        "start_date": "2024-05-21 00:00:00",
        "end_date": "2024-05-22 23:59:59"
    }
)
print(response.json())
```
</Request>

## Response fields

<ResponseField name="date" field-type="string" required="true">
  Date of the activity.
</ResponseField>

<ResponseField name="api_type" field-type="string" required="true">
  API called — `/mask`, `/unmask`, `/async-status`, etc.
</ResponseField>

<ResponseField name="status" field-type="string" required="true">
  `success` or `failure`.
</ResponseField>

<ResponseField name="user" field-type="string" required="true">
  User email associated with the calls.
</ResponseField>

<ResponseField name="logged_in_time" field-type="integer" required="false">
  Time active in the namespace, in seconds.
</ResponseField>
