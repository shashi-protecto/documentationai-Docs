---
title: "All Namespace Summary"
description: "API usage counts across all namespaces visible to the admin — for platform-level monitoring and tenant usage overview."
---

Returns usage counts **across all namespaces** visible to the admin. Commonly used by platform or super admins to monitor tenant-level activity.

## Endpoint

| Method | Endpoint |
|--------|----------|
| `GET` | `{baseurl}/api/vault/reports/all-namespace-summary` |

## Query parameters

<ParamField query="start_date" param-type="string" required="true">
  Start of the reporting window. Format: `YYYY-MM-DD HH:MM:SS`.
</ParamField>

<ParamField query="end_date" param-type="string" required="true">
  End of the reporting window. Format: `YYYY-MM-DD HH:MM:SS`.
</ParamField>

<ParamField query="next_page_token" param-type="string" required="false">
  Pagination token for large result sets.
</ParamField>

<Request tabs="JSON,cURL,Python">
```json
{
  "start_date": "2024-05-01 00:00:00",
  "end_date": "2024-05-31 23:59:59"
}
```

```bash
curl -X GET "{baseurl}/api/vault/reports/all-namespace-summary?start_date=2024-05-01+00:00:00&end_date=2024-05-31+23:59:59" \
  -H "Authorization: Bearer <ADMIN_USER_AUTH_KEY>"
```

```python
import requests

response = requests.get(
    "{baseurl}/api/vault/reports/all-namespace-summary",
    headers={
        "Authorization": "Bearer <ADMIN_USER_AUTH_KEY>"
    },
    params={
        "start_date": "2024-05-01 00:00:00",
        "end_date": "2024-05-31 23:59:59"
    }
)
print(response.json())
```
</Request>

## Response fields

<ResponseField name="namespace" field-type="string" required="true">
  Namespace name.
</ResponseField>

<ResponseField name="start_time" field-type="string" required="true">
  Reporting window start timestamp.
</ResponseField>

<ResponseField name="end_time" field-type="string" required="true">
