---
title: Identify and Mask (Auto-Detect)
description: >-
  Automatically detect and mask all PII in free-form text. Entity types, tokens,
  and detection rules are all driven by your active policy.
---
Use this for **free-form text** where entity types are unknown in advance. Protecto scans the text, detects sensitive entities based on the active policy, and returns a masked version with entity tags.d

## Endpoint

| Method | Route             | Headers                                    |
| ------ | ----------------- | ------------------------------------------ |
| PUT    | `/api/vault/mask` | `{"Authorization": "Bearer <AUTH_TOKEN>"}` |

<Callout kind="info" collapsed="false">
  To get the Authkey please contact [help@protecto.ai](mailto:help@protecto.ai)
</Callout>

## Request body

<ParamField body="mask" param-type="array" required="true" deprecated="false">
  List of free-form text inputs to analyze and mask.
</ParamField>

<ParamField body="mask[].value" param-type="string" required="true" deprecated="false">
  Free-form text containing potentially sensitive data.


</ParamField>

**Example**

<Request show-lines="true" default-tab="0" tabs={["JSON", "cURL", "Python"]}>
  ```json
  {
  "mask": [
  {
  "value": " Sarah Connors, a 34-year-old Caucasian woman residing at 12 Elm Street, Springfield, IL 62704, recently enrolled in TrendyShop’s premium membership program. During her visit to the Springfield location, her vehicle with registration number IL-4598-RM was logged into the parking system. Sarah, who holds a driving license numbered DL-IL-1987-20976, also registered her credit card (4532 7896 4512 3456) to enjoy 10% cashback on purchases. Additionally, her phone number (217-555-2020) and email address (sarah.connors88@example.com) and her company contact is www.xyz.com"
  }
  ]
  }
  ```

  ```bash
  curl -X PUT https://protecto-trial.protecto.ai/api/vault/mask \
    -H "Authorization: Bearer YOUR_AUTH_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "mask": [
        {
          "value": "Sarah Connors can be reached at 217-555-2020 or sarah.connors88@example.com"
        }
      ]
    }'
  ```

  ```python
  import requests

  response = requests.put(
      "https://protecto-trial.protecto.ai/api/vault/mask",
      headers={
          "Authorization": "Bearer YOUR_AUTH_TOKEN",
          "Content-Type": "application/json"
      },
      json={
          "mask": [
              {"value": "Sarah Connors can be reached at 217-555-2020 or sarah.connors88@example.com"}
          ]
      }
  )
  ```
</Request>

## Response fields

<ResponseField name="token_value" field-type="string" required="true" deprecated="false">
  The full input text with all detected entities replaced by tokens wrapped in entity tags.
</ResponseField>

<ResponseField name="individual_tokens" field-type="array" required="false" deprecated="false">
  Array of each individual entity detected and masked.

  <Expandable title="individual_tokens fields" default-open="false">
    <ResponseField name="value" field-type="string" required="true" deprecated="false">
      The original sensitive value.
    </ResponseField>

    <ResponseField name="token_value" field-type="string" required="true" deprecated="false">
      The token replacing the original value.
    </ResponseField>

    <ResponseField name="prefix" field-type="string" required="true" deprecated="false">
      The opening entity tag (e.g., `<PERSON>`).
    </ResponseField>

    <ResponseField name="suffix" field-type="string" required="true" deprecated="false">
      The closing entity tag (e.g., `</PERSON>`).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="toxicity_analysis" field-type="object" required="false" deprecated="false">
  Toxicity scores for the input text. Returned when enabled by policy.

  <Expandable title="Toxicity score categories" default-open="false">
    | Category          | Score range | Description                          |
    | ----------------- | ----------- | ------------------------------------ |
    | `toxicity`        | 0–1         | Overall likelihood of toxic content  |
    | `severe_toxicity` | 0–1         | Probability of severe toxic language |
    | `obscene`         | 0–1         | Likelihood of obscene content        |
    | `threat`          | 0–1         | Likelihood of threats                |
    | `insult`          | 0–1         | Likelihood of insults                |
    | `identity_attack` | 0–1         | Likelihood of identity-based attacks |

    Scores closer to `0` indicate low likelihood. Scores closer to `1` indicate high likelihood.
  </Expandable>
</ResponseField>

## Notes

- Detection and masking behavior are entirely **policy-driven** — no entity types or token names are required in the request.

- The exact tokenized output depends on the active policy.

- This mode is available on the **trial** environment.
