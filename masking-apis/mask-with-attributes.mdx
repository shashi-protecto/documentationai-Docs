---
title: Mask with Attributes
description: >-
  Attach custom metadata key-value pairs to masked values for downstream
  tracking, auditing, or contextual reference.
---
Attributes allow you to attach custom metadata to masked values. This is useful for associating contextual information — such as a page number, record ID, or source system — with each masked value.

## Endpoint

| Method | Route             | Headers                                    |
| ------ | ----------------- | ------------------------------------------ |
| PUT    | `/api/vault/mask` | `{"Authorization": "Bearer <AUTH_TOKEN>"}` |

<Callout kind="info" collapsed="false">
  To get the Authkey please contact [help@protecto.ai](mailto:help@protecto.ai)
</Callout>

## Request body

<ParamField body="mask" param-type="array" required="true" deprecated="false">
  List of values to mask.
</ParamField>

<ParamField body="mask[].value" param-type="string" required="true" deprecated="false">
  The raw sensitive value to mask.
</ParamField>

<ParamField body="mask[].format" param-type="string" required="false" deprecated="false">
  The format to apply for structure-preserving masking.
</ParamField>

<ParamField body="mask[].token_name" param-type="string" required="false" deprecated="false">
  The token type to use.
</ParamField>

<ParamField body="mask[].attributes" param-type="object" required="false" deprecated="false">
  Arbitrary key-value metadata to attach to the masked value.
</ParamField>

<Request show-lines="true" tabs={[]}>
  ```json
  {
    "mask": [
      {
        "value": "https://platform.openai.com/playground/chat",
        "format": "URL",

      }
    ]
  }
  ```

  ```bash
  curl -X PUT https://protecto-trial.protecto.ai/api/vault/mask \

    -d '{
      "mask": [

          "format": "URL",
          "token_name": "Text Token",
          "attributes": {
            "page_number": "1"
          }
        }
      ]

  ```

  ```python
  import requests
  ```

## Notes

- `attributes` is an **object** with string keys and string values.

- Attributes are stored alongside the token and can be used for downstream reference or auditing.

- Attributes do not affect the masking output — they are metadata only.
