<Update label="2024-10-15" description="v1.3.0" tags={["feature","improvement"]}>
  ## New Features

  - Added real-time protection for GenAI inputs and outputs, with dynamic masking policies.

  - Introduced support for custom classifiers in data discovery scans.

  ## Improvements

  - Reduced latency in API masking calls by `{25%}` for high-volume workloads.

  - Enhanced dashboard UI for policy management.

  ## Bug Fixes

  - Fixed intermittent failures in BigQuery connector during large scans.

  ## New Features

  - Auto-classification for unstructured data sources like S3 buckets.

  - New API endpoint for batch masking operations: `POST /v1/mask/batch`.

  ## Improvements

  - Better error handling in webhook integrations.

  ## Bug Fixes

  - Resolved issue where Redshift scans missed nested JSON fields.

  - Fixed token refresh logic in SDKs.

<Update label="2024-08-10" description="v1.1.0" tags={["breaking","feature"]}>
  ## Breaking Changes

  - Updated authentication to require `{API_KEY}` header instead of query param. Migrate by updating your requests.

  <CodeGroup show-lines="true" tabs={[]}>
    ```bash
    # Old (deprecated)
    curl "https://api.example.com/v1/scan" ?api_key=YOUR_API_KEY

    # New (required)
    curl -H "Authorization: Bearer YOUR_API_KEY" https://api.example.com/v1/scan
    ```

    ```javascript
    // Old
    fetch('/v1/scan?api_key=' + apiKey)

    // New
    fetch('/v1/scan', {
      headers: { Authorization: `Bearer ${apiKey}` }
    })
    ```
  </CodeGroup>

  ## New Features

  - Native Snowflake integration for live query masking.

  - Policy versioning with rollback support.

  ## Bug Fixes

  - Corrected false positives in PII detection for email fields.
</Update>
