<Update label="April 2026" description="v8.0.4 & v8.0.5 prod – Phase 3" tags={["Major Release"]}>
  #### Overview

  This release introduces enhancements across SharePoint integration (including on-premises support), monitoring and observability, AI model support, image generation, and overall user experience improvements.

  ---

  ### 1. SharePoint Integration (On-Prem)

  **Key capabilities**

  - Automated SharePoint file synchronization

  - Admin UI for connector configuration

  - Folder discovery and monitoring

  - Job, folder, and file-level sync monitoring

  - RAG tracking integration

  **Key benefits**

  - Eliminates manual document uploads

  - Improves operational efficiency

  - Enables centralized monitoring and management

  - Provides better visibility into document processing workflows

  ---

  ### 2. Health Monitoring & Observability

  **Key capabilities**

  - Latency Statistics dashboard

  - Chat latency visibility and monitoring

  **Key benefits**

  - Improved visibility into system performance

  - Easier monitoring of latency trends

  - Better operational insights for optimization

  ---

  ### 3. Gemini 3 Model Support

  **Key capabilities**

  - Gemini 3 Flash and Pro model support for text chat

  - Model selection support directly from UI

  **Key benefits**

  - Improved response quality and performance

  - Access to latest Gemini model capabilities

  - Greater flexibility in model selection

  ---

  ### 4. Google Nano Banana Image Generation

  **Key capabilities**

  - Image generation using Gemini-2.5-flash

  - Prompt-based image creation support

  **Key benefits**

  - Enhanced image generation capabilities within GPT Guard

  - Seamless multimodal AI experience

  - Improved user experience for image-based workflows

  ---

  ### 5. Customizable Tab Name

  **Key capabilities**

  - Configurable browser tab/application name support

  **Key benefits**

  - Improved branding and user experience

  - Consistent application identity across screens

  - Customer-specific naming flexibility

  ---

  ### 6. SharePoint Webpages Support

  **Supported page types under evaluation**

  - Wiki Pages

  - Web Part Pages

  - Site Pages

  **Notes**

  GPT Guard support will initially align with standard SharePoint page types to ensure reliable ingestion and processing.

  ---

  ### 7. Imagen4 Integration

  **Key capabilities**

  - Advanced image generation support within GPT Guard

  **Key benefits**

  - Enables richer multimodal AI workflows

  - Supports both text and image-based interactions

  - Enhances overall AI experience within the platform

  ---

  ### 8. Bug Fixes

  - Fixed incorrect masking of S4 values in RAG retrieval

  - Fixed incorrect conversation title generation for pasted prompts

  - Fixed masked data visibility during translation workflows

  - Fixed translation issue during document upload

  - Fixed behind the scene functionality issue

  - Improved masking detection for phone number entities

  - Fixed Arabic text misalignment issue

  - Fixed masked data visibility issue for end users on source click

  - Fixed repository creation failure issue in Update Monitoring
</Update>
